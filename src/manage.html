Updates on your terms

Connect Spotify once
Put your app credentials in .env, then run npm run spotify:connect. Open the Spotify consent link printed in your terminal. No secrets belong in this editor.
Upload the three Spotify secrets to GitHub Actions for scheduled updates. See README.md for the exact steps.
Deploy when you’re ready
Save your edits, run npm run check, then npm run deploy to review the changed files, commit and push. GitHub Actions builds and deploys the site.
Feed checks are scheduled every five minutes; GitHub can delay runs. Site visitors see the last successful check.
